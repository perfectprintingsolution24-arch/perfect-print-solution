PERFECT PRINT SOLUTION — WEDDING CARD PHOTO SETUP

This ZIP contains the website files plus 5 sample wedding invitation images already connected to the Wedding Cards catalogue.

WHAT IS INCLUDED
- wedding-cards.html updated to display photos from assets/cards/
- assets/cards/card-01.jpg through card-05.jpg
- Clicking a photo opens the existing product detail/zoom view from script.js
- WhatsApp quotation enquiry is retained

HOW TO ADD OR REPLACE PHOTOS
1. Extract this ZIP on your computer.
2. Open the assets/cards folder.
3. Replace card-01.jpg, card-02.jpg, etc. with your own photos. Keep the exact same filenames and JPG format. If your photo is PNG, save/export it as JPG first, or update the HTML filename to match.
4. Keep photos reasonably high-resolution (about 1200–2000 px tall) so zoom looks clear.
5. Upload/replace the extracted website files in the ROOT of your GitHub repository. Upload the complete assets/cards folder too.
6. Click Commit changes. Wait for GitHub Pages to publish, then refresh the Wedding Cards page.

IMPORTANT
- Upload the extracted files/folders, NOT the ZIP itself.
- This ZIP is prepared locally; it does not update the live website automatically.
- This only adds real sample photos to the Wedding Cards page. Other pages are not changed to use their own real product photos yet.
- Product zoom can enlarge the image, but cannot create detail missing from a low-resolution original.
