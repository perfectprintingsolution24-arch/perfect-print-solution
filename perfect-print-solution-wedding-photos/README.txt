Universal product interaction:
- Click product photo on supported product cards to open details.
- Use + / - / reset controls, or click the photo, to zoom. Mouse wheel zoom is supported on desktop.
- WhatsApp quotation link includes product title and product code where available.
- Product gallery layout is responsive: 3 columns on desktop, 2 on tablet, 1 on narrow mobile.
- Separate order form page is not included.

IMPORTANT PHOTO NOTE:
Product cards currently include placeholders where the site did not already have actual sample photographs. Replace those with your own product images for customers to inspect real designs. Zoom cannot create detail that is not present in the original image. Suggested product image size: 1200 x 1500 px (portrait) or 1200 x 1200 px (square), JPG/WebP, good quality. Keep image filenames and paths consistent with the HTML.

Publishing:
Extract this ZIP and upload/replace the files inside the repository root on GitHub, then commit the changes. Uploading the ZIP file itself does not publish the website.
